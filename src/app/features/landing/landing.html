Everyone sees the work that is theirs

Access follows the role, so people get what they need and nothing more.

Admin

Runs the organization.

  • Invite, deactivate and change the role of users
  • Create divisions, sections and pipelines
  • Change organization settings
  • Read every report

Section Head

Leads a section.

  • Manage pipelines for the section
  • Set up categories, tags and the task card
  • Assign work and keep tasks moving
  • Report on the section and its members

Staff

Gets the work done.

  • See assigned tasks in one list
  • Update tasks and move them forward
  • Comment and add links
  • See their own accomplishment report

Built so your data stays yours

Access is checked by the database itself, not only hidden in the interface.

Separate by organization

Every organization's tasks, people and reports are isolated by row-level access rules in the database. One organization cannot read another's data.
